Автономный мобильный веб-трекер для комплексного контроля терапии (Семавик, Оземпик, Семаглутид), динамики веса и суточного рациона с ИИ-распознаванием КБЖУ по фото этикеток и блюд.

[🚀 **Открыть приложение**](https://semavik-tracker.vercel.app) *(замените на ваш URL Vercel)*

---

## 🌟 Возможности

### 📈 Терапия и контроль веса
* **График инъекций:** пошаговый план по неделям с гибким выбором дозировок (0.25, 0.5, 1.0, 1.7, 2.4 мг).
* **Фиксация уколов:** сохранение точной даты и времени выполнения процедуры.
* **Интерактивный график:** визуализация динамики веса через Chart.js с ориентиром целевой массы.
* **Индикатор прогресса:** наглядный подсчёт оставшихся килограммов и процента выполнения цели.

### 🥗 Дневник питания и КБЖУ
* **Суточные нормы:** расчёт и отслеживание калорий, белков, жиров и углеводов.
* **Офлайн-база:** мгновенный поиск по популярным продуктам без задержек сети.
* **Open Food Facts:** подключение к международному каталогу штрихкодов.

### 📷 ИИ-сканер тарелок и этикеток (Gemini Vision)
* Извлечение КБЖУ на 100 г / 100 мл даже с мелких и бликующих этикеток.
* Распознавание номинального объёма тары (банки, бутылки, порции).
* **Умный калькулятор порции:** моментальный автопересчёт калоража под фактический вес съеденного.
* Сжатие фото на стороне браузера (HTML5 Canvas) для экономии мобильного трафика.

### 🔒 Приватность и безопасность
* Все данные хранятся исключительно на вашем устройстве (`localStorage`).
* Экспорт и импорт полной резервной копии в формате `.json`.
* Тёмная и светлая темы оформления.

## 📱 Установка как приложение (PWA)

Приложение работает прямо в браузере без установки из App Store:

* **iOS (Safari):** Нажмите кнопку **«Поделиться»** (квадрат со стрелкой) → выберите **«На экран „Домой“»**.
* **Android (Chrome):** Нажмите три точки в углу экрана → выберите **«Установить приложение»** или **«Добавить на главный экран»**.

---

## 🔑 Подключение бесплатного ИИ-сканера

Для работы распознавания по фото используется личный ключ Google Gemini API:

1. Получите бесплатный ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. В приложении нажмите на значок **Камеры** или шестерёнку настроек.
3. Вставьте ключ (`AIzaSy...`) и нажмите **«Сохранить»**.

> Бесплатного лимита Google AI Studio (до 15 запросов в минуту) с избытком хватает для ежедневного логирования питания одного человека.

## 🛠 Стек технологий

* **Интерфейс:** Vanilla JavaScript (ES6+), Semantic HTML5, CSS Custom Properties (адаптив под safe-area iOS).
* **Графика:** [Chart.js](https://www.chartjs.org/).
* **Нейросеть:** [Google Gemini 3.6 / Flash Vision API](https://ai.google.dev/).
* **База продуктов:** Встроенная локальная база + [Open Food Facts API](https://world.openfoodfacts.org/).

## ⚠️ Медицинский дисклеймер

Данное приложение является исключительно персональным дневником учёта и инструментом визуализации данных. Приложение не предоставляет медицинских консультаций, не ставит диагнозов и не назначает терапию. По всем вопросам дозировок, схемы приёма препаратов и коррекции рациона обязательно консультируйтесь с лечащим врачом.
